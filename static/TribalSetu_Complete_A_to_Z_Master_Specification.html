Complete Function-by-Function Technical Deep Dive All 15 System Functions
FUNCTION 1: ocr_entity_extractor(document_file)
Stage 1: Onboarding
📌 Ye Kya Hai?

Document Intelligence engine jo Aadhaar aur Marksheet se student details extract karta hai.

🎯 Ye Kyu Laga Hai?

Cyber cafe mein manual typing errors ki wajah se 40% tribal students ke form reject ho jaate the.

📥 Data Kahan Se Lega?

Student ke phone se uploaded Aadhaar aur Marksheet image se (ya DigiLocker Sandbox se).

⚙️ Underlying Logic

Tesseract 5.0 / PaddleOCR text nikaalta hai aur Regex + NER se Name, DOB, Marks, Roll No extract karta hai.

🔗 Agle Function Se Kaise Link Hai?

Extracted student profile JSON ko seedha FUNCTION 2 (Scheme Recommender) aur FUNCTION 10 (Fuzzy Identity Matcher) ko bhejta hai.

FUNCTION 2: recommend_mota_scheme(student_profile_json)
Stage 2: Recommendation
📌 Ye Kya Hai?

Smart Recommender jo student ki qualification ke mutabiq best central scheme suggest karta hai.

🎯 Ye Kyu Laga Hai?

Tribal students ko NFST (Ph.D. ₹31k/month) aur NOS (Abroad 100% Free) schemes ki jankari nahi hoti.

📥 Data Kahan Se Lega?

FUNCTION 1 ke extracted JSON (Current Education Level, Age, Marks) se.

⚙️ Underlying Logic

10th = Pre-Matric | UG/PG = Post-Matric | Ph.D. Enrolled = NFST | Foreign Offer Letter = NOS Overseas.

🔗 Agle Function Se Kaise Link Hai?

Selected Scheme ID ko FUNCTION 3 (Dynamic Slot Generator) ko pass karta hai.

FUNCTION 3: generate_dynamic_slots(scheme_id)
Stage 3: Dynamic Slots
📌 Ye Kya Hai?

Scheme-specific dynamic upload boxes generate karne wala schema engine.

🎯 Ye Kyu Laga Hai?

Har scheme ki requirements alag hain. Static form mein irrelevant documents mangna confusion create karta hai.

📥 Data Kahan Se Lega?

MoTA Officer dwara banaye gaye schemes_config.json policy database se.

⚙️ Underlying Logic

Post-Matric $\to$ Bonafide + Fee Receipt | NOS $\to$ Passport + Offer Letter + QS Ranking Proof.

🔗 Agle Function Se Kaise Link Hai?

UI par slots render karke uploaded files ko FUNCTION 4 (Document Classifier) ko pass karta hai.

FUNCTION 4: classify_document_type(uploaded_file, expected_slot)
Stage 3: Validation
📌 Ye Kya Hai?

Document Type Classifier jo check karta hai ki sahi slot mein sahi document upload hua hai ya nahi.

🎯 Ye Kyu Laga Hai?

Student galti se Passport slot mein Aadhaar card daal dete the, jisse babu form mahino latka dete the.

📥 Data Kahan Se Lega?

Uploaded file ke visual header aur text markers se.

⚙️ Underlying Logic

Passport $\to$ MRZ code check (`P

🔗 Agle Function Se Kaise Link Hai?

Sahi document ko FUNCTION 5 (DPDP Masker) aur FUNCTION 6 (Preprocessor) ko forward karta hai.

FUNCTION 5: mask_aadhaar_dpdp(document_text, image)
Stage 4: Privacy
📌 Ye Kya Hai?

Aadhaar ke pehle 8 digit ko kaala patti lagane (redact karne) wala regulatory privacy filter.

🎯 Ye Kyu Laga Hai?

Supreme Court aur DPDP Act 2023 ke mutabiq 12-digit raw Aadhaar number store karna illegal hai.

📥 Data Kahan Se Lega?

Uploaded Aadhaar card image aur extracted text se.

⚙️ Underlying Logic

Regex replace $\to$ XXXX-XXXX-1234 + OpenCV cv2.rectangle se photo par black-box draw karna.

🔗 Agle Function Se Kaise Link Hai?

Redacted safe document ko permanent audit trail database mein bhejta hai.

FUNCTION 6: preprocess_cv_image(image_path)
Stage 4: Computer Vision
📌 Ye Kya Hai?

Mobile photo ko scanner jaisa straight aur glare-free banane wala OpenCV pipeline.

🎯 Ye Kyu Laga Hai?

Bastar ke tribal students ke budget phone camera mein flash reflection aur tilted angle se OCR fail hota hai.

📥 Data Kahan Se Lega?

Raw mobile photo image path se.

⚙️ Underlying Logic

Canny Edge Detection + Perspective Warp se 90-degree deskew, Sauvola thresholding se flash glare remove karna.

🔗 Agle Function Se Kaise Link Hai?

Enhanced crystal-clear image ko hamare 5 Parallel Verification Pillars (Func 7, 8, 9, 10, 11) ko bhejta hai.

FUNCTION 7: detect_ela_tampering(image_path)
Stage 5: Forensics
📌 Ye Kya Hai?

Photoshop aur Canva pixel tampering detect karne wala Error Level Analysis (ELA) engine.

🎯 Ye Kyu Laga Hai?

Fraud applicants doosre ka certificate lekar Photoshop mein naam aur roll number badal dete hain.

📥 Data Kahan Se Lega?

Preprocessed certificate image se.

⚙️ Underlying Logic

Image ko 95% quality pe re-compress karke original se delta nikaalta hai. Edited box bright glow ban jata hai.

🔗 Agle Function Se Kaise Link Hai?

Returns Forensic_Score (0-100) jo FUNCTION 12 (Trust Scorer) ko pass hota hai.

FUNCTION 8: verify_qr_pki_signature(image_path)
Stage 5: Cryptography
📌 Ye Kya Hai?

State Government e-District QR code ki RSA-2048 Cryptographic Digital Signature verify karne wala engine.

🎯 Ye Kyu Laga Hai?

Agar kisi ne certificate text badal diya par QR purana chhod diya, ya fake QR banaya, toh turant pakadna.

📥 Data Kahan Se Lega?

Certificate ke scanned QR code se + State Sub-CA Public Key database se.

⚙️ Underlying Logic

State CA Public Key se payload decrypt karta hai. 1 bit change hone par bhi signature mismatch fail hoti hai.

🔗 Agle Function Se Kaise Link Hai?

Returns QR_Valid: True/False jo FUNCTION 12 (Trust Scorer) ko pass hota hai.

FUNCTION 9: verify_st_gazette_art342(state, candidate_caste)
Stage 5: Constitutional Law
📌 Ye Kya Hai?

Samvidhan ke Article 342 Central Gazette database se sub-caste ki legal ST validity cross-check karna.

🎯 Ye Kyu Laga Hai?

Har state ki ST list alag hoti hai. Inter-state migration ka ghapla karke illegal quota lene se rokna.

📥 Data Kahan Se Lega?

MoTA ki official statutory Gazette list (705+ Tribes) se jo hamare local SQLite DB mein hai.

⚙️ Underlying Logic

Exact relational SQL lookup: Check if candidate sub-caste exists in the official ST Order of that State.

🔗 Agle Function Se Kaise Link Hai?

Returns Gazette_Match: True/False jo FUNCTION 12 (Trust Scorer) ko pass hota hai.

FUNCTION 10: fuzzy_identity_triangulation(aadhaar_name, marksheet_name, dob, father_name)
Stage 5: NLP Matching
📌 Ye Kya Hai?

Tribal surnames ke spelling variations ("Budhu Ram Munda" vs "Budhu Munda") ko resolve karne wala engine.

🎯 Ye Kyu Laga Hai?

Chhoti si spelling variation ki wajah se innocent tribal student ka saal barbaad hone se bachana.

📥 Data Kahan Se Lega?

Aadhaar OCR text aur Marksheet OCR text se.

⚙️ Underlying Logic

Token Sort Ratio (85%). Agar score 75-90% hai, toh DOB 100% aur Father Name >= 90% anchor match se pass karta hai.

🔗 Agle Function Se Kaise Link Hai?

Returns Identity_Score: 0-100 jo FUNCTION 12 (Trust Scorer) ko pass hota hai.

FUNCTION 11: verify_npci_dbt_seeding(aadhaar_number, bank_details)
Stage 5: Banking / DBT
📌 Ye Kya Hai?

NPCI Aadhaar Payment Bridge (APB) seeding simulator jo DBT linkage verify karta hai.

🎯 Ye Kyu Laga Hai?

Hazaron crore ki scholarship bounce ho jaati hai kyunki student ka bank account Aadhaar-seeded nahi hota.

📥 Data Kahan Se Lega?

Bank IIN prefix list aur Aadhaar Verhoeff checksum algorithm se.

⚙️ Underlying Logic

Aadhaar checksum test + Bank IIN validation + NPCI APB schema handshake simulation.

🔗 Agle Function Se Kaise Link Hai?

Returns DBT_Active: True/False jo FUNCTION 12 (Trust Scorer) ko pass hota hai.

FUNCTION 12: calculate_composite_trust_score(scores_dict)
Stage 6: Triage Decision
📌 Ye Kya Hai?

Composite Trust Score Calculator jo 5 verification pillars ko mathematically combine karta hai.

🎯 Ye Kyu Laga Hai?

Babuon ki personal bias aur rishwatkhori khatam karke transparent mathematical decision lena.

📥 Data Kahan Se Lega?

Functions 7, 8, 9, 10, aur 11 ke individual output scores se.

⚙️ Underlying Logic

Score = 0.25*Forensics + 0.25*QR + 0.20*Gazette + 0.20*Identity + 0.10*DBT.

🔗 Agle Function Se Kaise Link Hai?

>=80% $\to$ FUNC 14 (Merit Engine) | 50-79% $\to$ FUNC 13 (Deficiency SMS) | <50% $\to$ Officer Fraud Desk.

FUNCTION 13: trigger_deficiency_sms(student_id, deficient_document)
Stage 6: Welfare Loop
📌 Ye Kya Hai?

Automated Deficiency Communication Engine jo 1-click re-upload link bhejta hai.

🎯 Ye Kyu Laga Hai?

Welfare mindset! Blurry photo par bache ko direct reject na karke 15 din ka re-upload mauka dena.

📥 Data Kahan Se Lega?

Yellow channel application ID aur student ke registered phone number se.

⚙️ Underlying Logic

Tokenized 15-day expiry link generate karke WhatsApp/SMS webhook trigger karta hai.

🔗 Agle Function Se Kaise Link Hai?

Re-uploaded document ko wapas FUNCTION 6 (Preprocessor) se hote huye pipeline mein re-verify karta hai.

FUNCTION 14: allocate_merit_slots(applicants_pool, scheme_id)
Stage 7: Selection
📌 Ye Kya Hai?

NOS Overseas (Oxford/Harvard) aur NFST ke limited slots ke liye unbiased merit selection engine.

🎯 Ye Kyu Laga Hai?

NOS mein pure desh mein sirf 100-125 slots hote hain. AI merit selection nepotism aur corruption rokta hai.

📥 Data Kahan Se Lega?

Green channel applicants ke marksheets aur foreign university offer letters se.

⚙️ Underlying Logic

Merit = 50% Marks + 30% QS World Ranking Weight + 20% Vulnerability Factor. Top 100 allocated + waitlist.

🔗 Agle Function Se Kaise Link Hai?

Awarded scholars ko FUNCTION 15 (Supervisor Portal) mein onboard karta hai.

FUNCTION 15: supervisor_quarterly_signoff(scholar_id, quarter_report)
Stage 8: Fellowship & DBT
📌 Ye Kya Hai?

Ph.D. scholars ke liye University Guide ka quarterly progress verification aur DBT milestone release portal.

🎯 Ye Kyu Laga Hai?

NFST fellowship 5 saal chalti hai. Research progress verify kiye bina sarkari fund release nahi ho sakta.

📥 Data Kahan Se Lega?

University Research Guide / HOD ke login credentials aur student research report se.

⚙️ Underlying Logic

Guide progress ko "Satisfactory" approve karta hai $\to$ PFMS XML API trigger $\to$ ₹93,000+ quarterly stipend direct DBT transfer.

🔗 Agle Function Se Kaise Link Hai?

Disbursement transaction status ko MoTA Executive Dashboard par live update karta hai!
